# Satoyama Nexus 要件 v0.1
基準：参照会話「構想を聞く」と2026-11-14のM0実装依頼。M0の実装詳細と将来要件を区別する。

## 確定事項
1. 里山保全を起点とする地域協働の実証用Webプラットフォーム。中心利用者は市民団体・一般市民・専門家。
2. Public（2026-11-25 オーナー判断で当初の Private から変更：GitHub アカウントを持たない関係者と共有する必要があるため）/ ryo-tanaka-phys/satoyama-nexus / pnpm Monorepo / Next.js・TypeScript / PostgreSQL・PostGIS。公開リポジトリのため秘密情報・個人情報・実在主体の非公開情報は従来以上に置かない。
3. 実在する活動の公開情報と、架空の参加者・模擬案件・模擬合意を明確に分離する。
4. AI一次推薦の後に人間の二次審査を行う。AIの出力だけで依頼・合意に進めない。
5. Phase 1の依頼・応答・調整・合意・実施準備はすべて模擬処理。実際の外部連絡を行わない。
6. 地理的適合性を将来評価する。距離だけで参加可能と断定しない。
7. 秘密情報をコミットしない。作業ブランチとPRで変更し、mainの統合にはユーザーの承認が必要。

## M0受け入れ条件
8. apps/web、packages/domain・matching・ai-review、data/fixtures、設計文書、CI、テンプレートを用意する。
9. 開発手順が再現可能で、ビルド・型検査・境界テストが実行できる。
10. PostgreSQL/PostGISのローカル設定と接続・地理型のスモーク検証を用意する。実行未確認は明記する。
11. 画面に実証表示を設け、実在活動の未登録状態と架空の参加者を区別する。

## 将来工程（番号維持）
M0 Foundation：開発環境・CI・設計文書。
M1 Domain：個人・団体・活動・協働案件の永続化。
M2 Matching：地理条件・参加意欲・技能を考慮した推薦。
M3 AI Review：AI一次評価・運営者二次審査・判断履歴。
M4 Collaboration：模擬依頼・応答・調整・合意・実施準備。
M5 Evidence：活動記録・知識継承・評価データ。
M6 Demonstration：実証シナリオ・品質検証・デモ公開。
Phase 1全体の完成条件は、活動提案から協働成立までの処理を模擬環境で再現・検証できること。M0のみでは満たさない。

## 未確定事項
認証・権限方式、ORM、AI事業者・モデル、推薦基準、距離・移動時間閾値、活動の調査対象、公開情報の利用条件、公開時期。
## 検討候補
MapLibre、Playwright、自治体・国・企業・支援機関との将来連携。導入済みとして扱わない。
## M0実装の限界
公開活動fixtureは出典未調査のため空。推薦は決定的な模擬アダプターのみ。実AI、DB永続化、認証、審査操作画面、連絡手段は未実装。
## 変更履歴
2026-11-14：既定事項を維持してM0基盤を作成。新規の事業要件の確定はしない。
2026-11-25：オーナー判断（人手・時間の制約によるやむを得ない変更）。(a) 要件2をPublicへ変更。(b) 要件5の「応答」を模擬協働の独立段階 `responded` として追加し、段階語彙を draft → requested → responded → coordinating → agreed → preparing に変更（M0語彙の拡張）。(c) 要件4を実装で強制：人間二次審査は現行改訂のAI一次推薦を参照しなければ受け付けない。
