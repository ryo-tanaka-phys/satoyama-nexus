# アーキテクチャ
モジュール分離したモノリス。web → domain / matching / ai-review、matching・ai-review → domain。domainはUI・DB・AI SDKに依存しない。

- apps/web：表示。M0では静的な実証入口のみ。
- domain：公開活動・模擬プロフィール・人間審査・模擬案件の型と順次遷移。
- matching：地理評価の境界。M0はnot-evaluatedを返し、適合性を捏造しない。
- ai-review：構造化推薦とproviderインターフェース。fixtureアダプターはAI呼び出しを行わない。
- PostgreSQL/PostGIS：M0は拡張初期化と接続検証のみ。M1でマイグレーションとリポジトリアダプターを追加する。

将来は公開活動を出典付きテーブル、模擬プロフィール・案件を別テーブルに保存し、案件にsimulation属性、審査に操作者・日時・理由、推薦にモデル・プロンプト版・根拠・制約を記録する。
位置はSRID 4326、距離比較はgeographyとGiSTインデックスを検討する。位置精度・欠損・移動可能性を別途扱う。M0にスキーマ確定は含めない。

Phase 1にはメール・SNS・外部連絡アダプターを設けない。実AI導入時も外部入力は非信頼データとし、人間審査を省略しない。
現在の型と遷移関数は認証・監査の安全性を保証しない。API導入時にはサーバー側の権限確認と改変不能な履歴が必要。
